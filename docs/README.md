# Peta dokumen RanahMenulis

Urutan sumber kebenaran bila ada yang bertentangan: keputusan client → PRD v0.2 → [DESIGN.md](../DESIGN.md) → salinan artifact di `desain/` (arsip). Butir bertanda `[usulan]` atau `[konfirmasi]` belum disetujui client.

| Lokasi | Isi |
| --- | --- |
| [catatan-keputusan-client.md](catatan-keputusan-client.md) | Keputusan dan konfirmasi client. Sumber kebenaran pertama. |
| [prd/](prd) | Sumber PRD v0.2, satu berkas per bagian (00–28), `CHANGELOG.md`, dan `gabung.py`. Edit di sini, bukan di berkas gabungan. |
| [PRD RanahMenulis v0.2.md](PRD%20RanahMenulis%20v0.2.md) | Hasil gabungan `prd/gabung.py`. Hanya dibaca atau dikirim; jangan diedit langsung. |
| [produk/](produk) | Dokumen turunan PRD: PRD Ringkas untuk client, MVP Scope (roadmap dan urutan rilis), Brief Desain, Copy Landing. |
| [desain/](desain) | Arsip artifact Claude Design (`aplikasi/`, `landing/`, `sistem-desain/`), `Catatan Slicing.md`, `Prompt Lanjut Slicing.md`, dan prompt landing. Lihat [desain/README.md](desain/README.md). |
| [referensi/](referensi) | Acuan eksternal: `novlr/` (isi dalam aplikasi, riset desain produk, peta gap, dan tangkapan layar `novlr-ss/`) dan referensi gaya Medium. |
| [arsip/](arsip) | Bahan mentah dan biner yang tidak diedit lagi: prompt penyusunan PRD v0.1, transkrip rapat client, PDF PRD v0.1 dan v0.2, Audit dan Roadmap, presentasi Kondisi dan Rencana. |
