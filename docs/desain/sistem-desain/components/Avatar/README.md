# Avatar

Lingkaran penanda penulis, dengan foto bila ada dan inisial bila tidak.

- Ukuran: 20 (baris "di Grup oleh"), 32 (catatan, bilah atas), 44 (baris penulis), 64 (blok "Ditulis oleh"), 88 (profil).
- `radius-full`. Tanpa foto: dua huruf inisial `ink-muted` 500 di atas `subtle`, ukuran huruf 40% diameter.
- Foto: `object-fit: cover`, tanpa border, tanpa cincin status.
- Selalu didampingi nama di dekatnya atau `aria-label`.
- Grup memakai avatar yang sama; logo grup menyusul di Fase 2.
