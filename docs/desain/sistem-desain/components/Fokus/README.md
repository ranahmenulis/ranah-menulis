# Fokus

Penanda fokus keyboard: outline 2px `ink`, offset 2px, pada semua elemen interaktif, lewat `:focus-visible`.

- Mengikuti bentuk elemen: pill pada tombol dan chip, lurus pada input dan tautan.
- Di bagian yang dibalik (daftar tunggu), `ink` ikut tema lawan sehingga outline tetap kontras.
- Rasio outline terhadap latar 17,6:1 (terang) dan 16,0:1 (gelap).
- Tidak pernah `outline: none` tanpa pengganti.
