# Tautan

Tautan selalu berwarna `ink`; tidak ada tautan biru.

- Di teks karya: garis bawah selalu terlihat, tebal 1px, offset 3px.
- Di antarmuka: tanpa garis bawah, garis bawah muncul saat hover dan fokus.
- Tautan yang membuka situs lain memakai `<a href>` biasa; tidak memakai ikon panah kecuali benar-benar keluar dari RanahMenulis.
