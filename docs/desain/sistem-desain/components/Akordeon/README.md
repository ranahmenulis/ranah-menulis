# Akordeon

Daftar tanya jawab bergaris rambut; setiap pertanyaan membuka jawabannya di tempat.

- Dibuat dengan `<details>`/`<summary>` asli agar bisa dipakai keyboard tanpa skrip.
- Garis 1px `line` di atas daftar dan di bawah tiap butir. Tanpa kotak, tanpa latar.
- Pertanyaan [usulan]: serif `read-subtitle` 22/32 400 `ink`, padding vertikal 24. Ikon tambah 20px `ink-muted` di kanan, menjadi garis kurang saat terbuka.
- Jawaban: `text-base` 16/26 `ink-muted`, lebar maksimal 680, padding bawah 28.
- Butir pertama boleh terbuka secara bawaan. Tanpa animasi buka [usulan], sesuai aturan "gerak hanya di hero".
- Jawaban yang faktanya belum pasti ditulis `[konfirmasi client]`.
