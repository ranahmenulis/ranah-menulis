# Milestone dan perayaan streak [usulan]

Daftar pencapaian di Dasbor Streak (PRD STK-06). Terbuka dan terkunci dibedakan dengan isi titik dan bobot teks, tidak dengan warna.

- `rm-ms`: titik 20px, judul `text-base` 500, keterangan `text-xs`, tanggal atau sisa di kanan.
- Terbuka: `rm-dot-full` + tanggal diraih. Terkunci (`is-locked`): `rm-dot-lock` (cincin putus-putus `ink-faint`), judul `ink-muted` 400, sisa syarat sebagai fakta ("130 kata lagi"), bukan ajakan.
- Baru terbuka: `rm-tag` "Baru" bergaris, satu kali, sampai halaman dibuka lagi. Tanpa lencana bergambar, konfeti, atau suara.
- Perayaan target harian: `rm-dot-fill` mengisi cincin hari ini dengan `transform: scale` 300 ms, sekali, jeda 200 ms. Reduced-motion: langsung terisi.
- Kartu pencapaian untuk dibagikan adalah Fase 2 (STK-07): tidak ada tombol Bagikan di sini.
- Daftar milestone dan syaratnya ditetapkan produk (Q-10); contoh di papan adalah usulan.
