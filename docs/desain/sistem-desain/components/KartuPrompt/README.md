# Kartu prompt dan kit inspirasi [usulan]

Isi drawer bantuan Studio (PRD STD-11). Laci kanan 360px dengan dua tab: Kit inspirasi dan Prompt.

- Kit inspirasi: daftar bergaris `rm-kit-item` (Ide cerita, Kalimat pembuka, Kamus diksi, Pertanyaan refleksi, Ide judul, Kalimat penutup, Kamus transisi), jumlah butir di kanan.
- Prompt: `rm-prompt` berisi teks serif 16/26 dan tombol teks kecil "Salin". Setelah disalin, label menjadi "Tersalin" + centang selama 2 detik, lalu kembali. Tidak memakai toast.
- Kalimat pengantar satu baris di atas daftar menjelaskan bagian yang sedang dibuka.
- Ponsel: drawer menjadi lembar bawah setinggi 80% layar.
- Isi kit statis, dikelola tim. Konsumen menyediakan: daftar butir, penangan salin.
