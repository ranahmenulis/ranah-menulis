# TombolHero

Tombol primer versi besar untuk hero landing, satu-satunya isian tinta di layar pertama.

- [usulan] Tinggi 48, padding 28, teks 16/24 500. DESIGN.md hanya punya tinggi 40 dan 32; ukuran 48 dipakai agar seimbang dengan judul 96px dan nyaman diketuk di ponsel.
- Warna dan keadaan sama dengan tombol primer (hover 0.85, press 0.72, fokus outline 2px).
- Pendamping opsional: satu tombol teks ("Lihat cara kerjanya") yang menggulir ke bagian berikutnya. Tidak ada tombol sekunder bergaris di sebelahnya.
- Ponsel: selebar kolom (100%) [usulan].
