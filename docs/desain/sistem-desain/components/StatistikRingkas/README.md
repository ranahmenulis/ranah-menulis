# Statistik ringkas [usulan]

Tiga angka di bawah kalender Streak. Setiap angka punya label yang menjelaskan artinya; tidak ada angka tanpa makna dan tidak ada grafik di sini (grafik ada di halaman Statistik).

- `rm-stats`: tiga kolom bergaris atas, angka serif 28/34 `tabular-nums`, label `text-xs ink-muted`.
- Ponsel: tetap tiga kolom bila muat, label boleh dua baris.
- Data belum cukup: kolom diganti satu kalimat tanpa ambang hari, "Belum cukup data untuk statistik. Tulis beberapa hari, lalu angkanya muncul di sini." (PRD STK-05). Ambang data minimum **[konfirmasi]**.
