# Pemberitahuan netral [usulan]

Kabar yang perlu dibaca tetapi bukan galat: zona waktu perangkat berbeda dari profil, target baru berlaku besok, perubahan disimpan di perangkat saat offline.

- `rm-notice`: latar `subtle`, ikon info `ink`, teks `text-sm ink`, satu tombol teks opsional. Tidak memakai merah dan tidak pernah satu-satunya penanda bersama warna.
- Galat tetap memakai `rm-banner` (`danger-subtle`).
- Satu pemberitahuan per blok. Bisa ditutup bila tidak lagi relevan.
