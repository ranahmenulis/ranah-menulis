# PenandaVisibilitas

Ikon + teks kecil yang selalu memberi tahu siapa yang bisa melihat sebuah tulisan.

- `text-xs ink-muted`, ikon 16: **Pribadi** (gembok), **Grup: Nama Grup** (dua orang), **Publik** (globe).
- Selalu di dekat judul dokumen dan di dialog Bagikan. Tidak pernah disembunyikan di menu.
- Mengubah ke Publik selalu lewat dialog yang menyebut persis teks mana yang akan tampil.
- Dokumen Studio selalu Pribadi; yang menjadi Grup atau Publik adalah salinan yang dibagikan.
