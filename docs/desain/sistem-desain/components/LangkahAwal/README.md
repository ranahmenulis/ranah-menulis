# Langkah awal pengguna baru [usulan]

Tiga langkah di Beranda untuk pengguna yang belum punya data, mengikuti perjalanan inti PRD 13.1: lengkapi profil, tetapkan target harian, tulis dokumen pertama. Hilang setelah ketiganya selesai.

- `rm-steplist`: baris bergaris; `rm-check` cincin untuk yang belum, terisi tinta dengan centang untuk yang selesai.
- Langkah berikutnya punya aksi tombol teks di kanan. Tidak ada persentase, lencana, poin, atau konfeti.
- Konsumen menyediakan: tiga langkah dengan status dan tujuan.
