# NavTablet

Rail kiri 72px untuk lebar 768–1023, berisi ikon 24 dengan label kecil di bawahnya.

- Butir: ikon 24 + label `text-xs` [usulan: DESIGN.md hanya menyebut "label kecil"], padding vertikal 8, gap 4.
- Aktif: `ink` 500 + ikon Fill; lainnya `ink-muted`.
- Garis kanan 1px `line`. Bilah atas tetap ada di atas rail.
- Kelola dan Admin masuk lewat menu Profil.
