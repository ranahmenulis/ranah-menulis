# Blok Hari ini [usulan]

Bagian atas Beranda untuk pengguna yang masuk (Brief 4A, PRD PLT-10, sementara). Menjawab "apa yang perlu aku lakukan sekarang", lalu feed di bawahnya.

- `rm-today`: garis atas `line-strong`, lalu baris `rm-today-row` bergaris: label 160px, isi, aksi. Bukan widget berkotak.
- Urutan tetap: Lanjutkan menulis, Progres hari ini, Perlu perhatian (maksimal tiga butir), Proyek saya, Notifikasi baru.
- Blok tanpa isi tidak dirender sama sekali; tidak ada "tidak ada data".
- Satu tombol primer: "Lanjutkan menulis" (atau "Mulai menulis" bila belum ada dokumen). Aksi lain tombol teks.
- Perlu perhatian (`rm-attn`): pill status atau ikon + kalimat apa yang menunggu + tenggat. Untuk Organizer, Editor, Juri, Mentor, dan Admin isinya berganti, strukturnya sama; lebih dari tiga butir: tautan ke Kelola.
- Memuat: kerangka per baris. Galat: baris itu saja diganti `rm-banner` dengan Coba lagi.
- Ponsel (`rm-today--s`): label di atas isi, tinggi blok paling banyak satu layar.
