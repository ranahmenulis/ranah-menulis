## 4. Pelajaran teknis

- Server dev di port 3001 (port 3000 milik aplikasi lain). **`next start` (produksi) mematikan peran dev**, jadi uji peran harus lewat server dev. Jalankan server dev di latar (`(npx next dev -p 3001 > /dev/null 2>&1 &)`), tunggu ±12 detik, **panaskan tiap rute yang diuji dengan `curl`** (kompilasi pertama bisa >15 detik dan membuat klik skrip "tidak berpindah"), matikan sesudahnya **lewat port**: `powershell -NoProfile -Command "Get-NetTCPConnection -LocalPort 3001,9333 -State Listen | % { Stop-Process -Id $_.OwningProcess -Force }"`. **Jangan mematikan proses dengan filter `CommandLine -like '*next*'`.** Setelah ubah `@utility` di `globals.css`, verifikasi lewat `npm run build`. Rute dinamis baru butuh `npx next typegen`; `usePathname()` di rute dinamis butuh `<Suspense>`.
- **Windows: perintah shell terlalu panjang ditolak** ("too long to hand to the shell"). Tulis skrip Python atau `.mjs` panjang dengan alat Write ke scratchpad, lalu jalankan; jangan menaruh heredoc besar di satu perintah Bash. Skrip Python yang mengganti teks sebaiknya memakai `assert a in s` agar kegagalan tidak diam-diam.
- **Uji peramban tanpa alat peramban:** setir Chrome lewat CDP. `C:\Program Files\Google\Chrome\Application\chrome.exe --headless=new --remote-debugging-port=9333 --user-data-dir=<tmp>` (profil baru per jalan), ambil `ws://` dari `/json`, Node 26 punya `WebSocket` bawaan; skrip `.mjs` di scratchpad (contoh yang bekerja di sesi lalu: `org-check.mjs`, `pay-check.mjs`, `stage-check.mjs`, `juri-check.mjs`, `results-check.mjs`; kalau tidak ada, tulis ulang). Klik asli `Input.dispatchMouseEvent`; mengetik `Input.insertText`; Enter butuh `text: String.fromCharCode(13)`; 375 lewat `Emulation.setDeviceMetricsOverride`; `scrollIntoView` pakai `behavior: "instant"`. `evaluate` tidak bisa mengembalikan elemen DOM. **Mulai dari `about:blank` sessionStorage ditolak**: navigasi ke halaman aplikasi dulu. **Chrome headless berbahasa Inggris**: label nav jadi "Home/Explore". Halaman yang di-cache Next tetap ada di DOM tersembunyi: saring elemen yang terlihat (`getBoundingClientRect().width > 0`), dan **tunggu teks yang hanya ada di layar tujuan** (bukan teks yang juga ada di layar asal). Tunggu ±500 ms setelah dialog terbuka sebelum mengklik. Isi IndexedDB langsung dari skrip (`ranah-projects` store `submissions`, `ranah-kelas`, `ranah-solo`; keyPath `id`) dan localStorage (`ranah.registrations`, `ranah.mentorTasks`, `ranah.organizerProjects`, `ranah.staffAssignments`, `ranah.juryScores`, `ranah.judgingLog`, `ranah.contestStages`, `ranah.contestResults`). - **Aturan yang ditampilkan form harus ditegakkan di tempat data ditulis** (hasil `code-review`): kunci arsip, kategori, zona, dan biaya ada di `buildProject`/`lockErrors`, bukan hanya `disabled` di formulir; aksi membaca ulang pendaftaran, log, dan tahap saat tombol ditekan; hapus draf ikut menghapus penugasannya; tenggat yang tanggalnya tidak diubah tetap momen persisnya.
- Dialog yang pemicunya hilang setelah aksi tidak bisa mengembalikan fokus: pindahkan ke baris status atau judul (`requestAnimationFrame`). Tanda yang disetel setelah `await` bisa terlambat: setel **sebelum** menulis. `getAllByRole("listitem")` tercampur bila satu layar memuat beberapa daftar: pakai `within(...)`. Komponen yang membaca store bawaan (IndexedDB) di jsdom jatuh ke galat: beri prop `store` (dan teruskan ke anak, mis. `TasksTab`). Tes yang menambah beberapa submission ke satu store butuh `docId` berbeda. Label bidang opsional berakhiran "(opsional)": cari dengan regex `/^Kuota/`. Kriteria lomba contoh: "Lomba Cerpen Hujan 2026" punya empat kriteria dan tiga hadiah, anonim, dan satu-satunya yang ditugaskan ke Juri dummy.
- **Dari 6f-6:** kedaluwarsa pembayaran dihitung dari waktu (`registeredAt` + `HOLD_MS`), tidak disimpan; pembaca daftar pendaftaran memakai `liveRegistration(s)`. Fixture tes pendaftaran "menunggu" memakai jam nyata. Token `line-strong` adalah warna gelap: pakai `ink-muted` untuk penanda lembut. Kode QRIS adalah contoh berlabel. `maxWorkers: 6` tidak mempercepat tes.
- Masukan client (Fahmi) soal Beranda dicatat di Catatan Slicing untuk tahap enhance UI; jangan dikerjakan sekarang.
