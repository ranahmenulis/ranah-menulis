## 3. Aturan kerja yang wajib

- **Klarifikasi sebelum eksekusi** (butir 2): tanyakan alur, keadaan kosong dan gagal, batas, dan privasi, dengan opsi konkret dan rekomendasi. Rujuk PRD atau catatan keputusan bila jawabannya sudah ada. Butir `[usulan]`/`[konfirmasi]` belum disetujui client; tandai di UI dan kode.
- **Rencana sebelum perubahan besar** (butir 3): lebih dari 5 berkas, lebih dari satu modul, database, atau konfigurasi = rencana, lalu **berhenti sampai user menyetujui eksplisit**. Persetujuan satu rencana tidak berlaku untuk rencana lain. Format rencana yang diterima user di 6g: tujuan, layar, keputusan desain [usulan] dengan rekomendasi, berkas (baru, diubah, dihapus, tes), verifikasi, risiko, cara membatalkan, pertanyaan terbuka. User biasanya menjawab "ikuti rekomendasimu".
- **Tes selama 6g (user, 17 November 2026):** **tes penuh tidak dijalankan per sub-langkah; hanya sekali setelah 6g-9 selesai** (atau sebelum push). Per sub-langkah wajib: Prettier dan ESLint, `npx tsc --noEmit`, dan tes terarah (`npx vitest run tests/features/kelola tests/features/projects tests/features/notifications tests/features/community` cukup luas untuk 6g, ±2 menit), termasuk tes baru. **Saat mengubah fixture atau fungsi bersama (katalog proyek, `useCommunity`, notifikasi, penugasan), jalankan folder-folder yang memakainya (juga `home`, `saved`, `profile` untuk Community).** `npm run build` bila menyentuh routing atau config. Laporkan jelas bahwa tes penuh belum dijalankan.
- **Setiap layar penuh wajib punya jalan keluar yang terlihat.** Dialog modal yang diikuti `router.push/back` menutup dirinya dulu. Uji sebagai **alur lintas layar** dengan klik mouse sungguhan (`Input.dispatchMouseEvent`) **dan** keyboard saja; fokus kembali ke pemicu (atau ke baris status bila pemicunya hilang) setelah dialog.
- **Rutinitas tiap sub-langkah**: komponen yang ada, cek 375 dan 1280 di peramban nyata (mode gelap dan **terang**), lalu `code-review` (verifikasi tiap temuan; sekitar separuh valid) dan `simplify` (empat agen paralel; terapkan yang aman, catat yang ditunda dan alasannya). User biasanya memintanya setelah sub-langkah selesai; tawarkan, jangan jalankan sebelum diminta. Hindari `apple-design` dan `choreograph`. `design-taste-frontend` hanya untuk landing.

## 4. Pelajaran teknis

- Server dev di port 3001 (port 3000 milik aplikasi lain). **`next start` (produksi) mematikan peran dev**, jadi uji peran harus lewat server dev. Jalankan server dev di latar (`(npx next dev -p 3001 > /dev/null 2>&1 &)`), tunggu ±12 detik, **panaskan tiap rute yang diuji dengan `curl`**, matikan sesudahnya **lewat port**: `powershell -NoProfile -Command "Get-NetTCPConnection -LocalPort 3001,9333 -State Listen | % { Stop-Process -Id $_.OwningProcess -Force }"`. **Jangan mematikan proses dengan filter `CommandLine -like '*next*'`.** Setelah ubah `@utility` di `globals.css`, verifikasi lewat `npm run build`. Rute dinamis baru butuh `npx next typegen`; `usePathname()` di rute dinamis butuh `<Suspense>`.
- **Windows: perintah shell terlalu panjang ditolak.** Tulis skrip Python atau `.mjs` panjang dengan alat Write ke scratchpad, lalu jalankan. Skrip Python yang mengganti teks memakai `assert a in s`. **Prettier mengubah susunan baris**, jadi string pencarian untuk penggantian otomatis harus dibaca ulang dari berkas, bukan diingat. `sed` pada baris berisi beberapa `import` sebaris bisa memotong baris.
- **Uji peramban tanpa alat peramban:** setir Chrome lewat CDP. `C:\Program Files\Google\Chrome\Application\chrome.exe --headless=new --remote-debugging-port=9333 --user-data-dir=<tmp>`, ambil `ws://` dari `/json`, Node 26 punya `WebSocket` bawaan; skrip `.mjs` di scratchpad (contoh sesi lalu: `admin-check.mjs`, `mod-check.mjs`; kalau hilang, tulis ulang). Klik asli `Input.dispatchMouseEvent`; mengetik `Input.insertText`; Enter butuh `text: String.fromCharCode(13)`; 375 lewat `Emulation.setDeviceMetricsOverride` **dengan `mobile: false`** (`mobile: true` melebarkan viewport menjadi ±628 dan membuat semua halaman tampak melebar); ukur `document.documentElement.scrollWidth`. `scrollIntoView` pakai `behavior: "instant"`. `evaluate` tidak bisa mengembalikan elemen DOM. **Mulai dari `about:blank` sessionStorage ditolak**: navigasi ke halaman aplikasi dulu. Chrome headless berbahasa Inggris. Halaman yang di-cache Next tetap ada di DOM tersembunyi: saring elemen yang terlihat, dan **tunggu teks yang hanya ada di layar tujuan**. Tunggu ±500 ms setelah dialog terbuka sebelum mengklik, dan ±400 ms setelah dialog menutup sebelum memeriksa fokus baris status. `innerText` chip berisi baris baru (`"Baru\n4"`). Peran dev lewat `?sebagai=administrator` di alamat (disimpan di sessionStorage). Isi IndexedDB langsung dari skrip (`ranah-projects`, `ranah-kelas`, `ranah-solo`, `ranah-community`) dan localStorage (`ranah.registrations`, `ranah.mentorTasks`, `ranah.organizerProjects`, `ranah.staffAssignments`, `ranah.juryScores`, `ranah.judgingLog`, `ranah.contestStages`, `ranah.contestResults`, `ranah.roleGrants`, `ranah.suspensions`, `ranah.auditLog`, `ranah.reports`, `ranah.moderation`). - `token line-strong` adalah warna gelap: pakai `ink-muted` untuk penanda lembut. Grid yang punya anak `overflow-x-auto` butuh `grid-cols-[minmax(0,1fr)]` supaya tidak melebar.
- Masukan client (Fahmi) soal Beranda dicatat di Catatan Slicing untuk tahap enhance UI; jangan dikerjakan sekarang.
