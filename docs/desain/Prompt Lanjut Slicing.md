## 4. Pelajaran teknis

- Server dev di port 3001 (port 3000 milik aplikasi lain). **`next start` (produksi) mematikan peran dev**, jadi uji peran harus lewat server dev. Jalankan server dev di latar (`(npx next dev -p 3001 > /dev/null 2>&1 &)`), tunggu ±12 detik, **panaskan tiap rute yang diuji dengan `curl`**, matikan sesudahnya **lewat port**: `powershell -NoProfile -Command "Get-NetTCPConnection -LocalPort 3001,9333 -State Listen | % { Stop-Process -Id $_.OwningProcess -Force }"`. **Jangan mematikan proses dengan filter `CommandLine -like '*next*'`.** Setelah ubah `@utility` di `globals.css`, verifikasi lewat `npm run build`. Rute dinamis baru butuh `npx next typegen`; `usePathname()` di rute dinamis butuh `<Suspense>`.
- **Windows: perintah shell terlalu panjang ditolak.** Tulis skrip Python atau `.mjs` panjang dengan alat Write ke scratchpad, lalu jalankan. Skrip Python yang mengganti teks memakai `assert a in s`. **Prettier mengubah susunan baris**, jadi string pencarian untuk penggantian otomatis harus dibaca ulang dari berkas, bukan diingat. `sed` pada baris berisi beberapa `import` sebaris bisa memotong baris.
