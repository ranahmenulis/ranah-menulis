## 4. Pelajaran teknis

- Server dev di port 3001 (port 3000 milik aplikasi lain). **`next start` (produksi) mematikan peran dev**, jadi uji peran harus lewat server dev. Jalankan server dev di latar (`(npx next dev -p 3001 > /dev/null 2>&1 &)`), tunggu ±12 detik, **panaskan tiap rute yang diuji dengan `curl`**, matikan sesudahnya **lewat port**: `powershell -NoProfile -Command "Get-NetTCPConnection -LocalPort 3001,9333 -State Listen | % { Stop-Process -Id $_.OwningProcess -Force }"`. **Jangan mematikan proses dengan filter `CommandLine -like '*next*'`.** Setelah ubah `@utility` di `globals.css`, verifikasi lewat `npm run build`. Rute dinamis baru butuh `npx next typegen`; `usePathname()` di rute dinamis butuh `<Suspense>`.
- **Windows: perintah shell terlalu panjang ditolak.** Tulis skrip Python atau `.mjs` panjang dengan alat Write ke scratchpad, lalu jalankan. Skrip Python yang mengganti teks memakai `assert a in s`. **Prettier mengubah susunan baris**, jadi string pencarian untuk penggantian otomatis harus dibaca ulang dari berkas, bukan diingat. `sed` pada baris berisi beberapa `import` sebaris bisa memotong baris.
- **Uji peramban tanpa alat peramban:** setir Chrome lewat CDP. `C:\Program Files\Google\Chrome\Application\chrome.exe --headless=new --remote-debugging-port=9333 --user-data-dir=<tmp>`, ambil `ws://` dari `/json`, Node 26 punya `WebSocket` bawaan; skrip `.mjs` di scratchpad (contoh sesi lalu: `admin-check.mjs`, `mod-check.mjs`; kalau hilang, tulis ulang). Klik asli `Input.dispatchMouseEvent`; mengetik `Input.insertText`; Enter butuh `text: String.fromCharCode(13)`; 375 lewat `Emulation.setDeviceMetricsOverride` **dengan `mobile: false`** (`mobile: true` melebarkan viewport menjadi ±628 dan membuat semua halaman tampak melebar); ukur `document.documentElement.scrollWidth`. `scrollIntoView` pakai `behavior: "instant"`. `evaluate` tidak bisa mengembalikan elemen DOM. **Mulai dari `about:blank` sessionStorage ditolak**: navigasi ke halaman aplikasi dulu. Chrome headless berbahasa Inggris. Halaman yang di-cache Next tetap ada di DOM tersembunyi: saring elemen yang terlihat, dan **tunggu teks yang hanya ada di layar tujuan**. Tunggu ±500 ms setelah dialog terbuka sebelum mengklik, dan ±400 ms setelah dialog menutup sebelum memeriksa fokus baris status. `innerText` chip berisi baris baru (`"Baru\n4"`). Peran dev lewat `?sebagai=administrator` di alamat (disimpan di sessionStorage). Isi IndexedDB langsung dari skrip (`ranah-projects`, `ranah-kelas`, `ranah-solo`, `ranah-community`) dan localStorage (`ranah.registrations`, `ranah.mentorTasks`, `ranah.organizerProjects`, `ranah.staffAssignments`, `ranah.juryScores`, `ranah.judgingLog`, `ranah.contestStages`, `ranah.contestResults`, `ranah.roleGrants`, `ranah.suspensions`, `ranah.auditLog`, `ranah.reports`, `ranah.moderation`). Mode terang: `document.cookie='theme=light; path=/'`.
- Next 16 `cacheComponents` menyimpan halaman sebelumnya tersembunyi: modal terbuka di sana membuat halaman tujuan inert (sudah ditangani di `Dialog` dan `Drawer`, tetapi tutup dialog sebelum berpindah). **Alamat adalah sumber kebenaran** untuk filter dan tab (`useUrlFilter`); kotak cari tidak boleh disinkronkan ulang dari alamat saat mengetik (alamat tertinggal dari ketikan).
